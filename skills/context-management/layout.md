# Раскладка документов

Одинакова во всех проектах команды. Отклонение — находка, даже если сам документ
хорош.

| Путь | Владеет |
|---|---|
| `AGENTS.md` | правила, действующие всегда, и индекс документов |
| `README.md` | что за проект и как начать — для человека |
| `docs/constitution/mission.md` | зачем проект и что считается успехом |
| `docs/constitution/tech-stack.md` | язык, запуск, раскладка модуля |
| `docs/constitution/roadmap.md` | что делается и что дальше — включая пути, которых ещё нет |
| `docs/testing.md` | как писать и запускать тесты |
| `docs/specs/features/<feat>/` | материалы одной задачи: спецификация, план |
| `docs/review/` | отчёты выверки — улики, не норма |
| `misc/` | временные файлы на разбор: удалить или найти дом |
| `skills/<name>/` | как выполнять рабочий процесс |

Других мест для этих документов не заводить. Второй каталог конституции, второй
каталог спецификаций, папка с отчётами рядом с задачей — одна норма в двух
копиях.
Документа в `docs/` вне таблицы не бывает: файл в `docs/`, которого нет в этой
таблице, — находка. Второй каталог документов в корне (`notes/`, `doc/`,
`документация/`) — та же находка: имя может отличаться, роль та же. Перенос,
объявленный в `roadmap.md` с названным концом, делает находку временной, но не
законной.
Новый вид документа — повод добавить строку в таблицу; `roadmap.md` её не
заменяет.
Временный файл живёт в `misc/`; принять его как документ или удалить решает
`roadmap.md`, а не эта раскладка.

`AGENTS.md` грузится в каждую сессию, остальное — по необходимости: разница в
цене, а не в важности.
