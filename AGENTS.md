# AGENTS.md

`docs/constitution/mission.md` и `docs/GLOSSARY.md` — прочитать до первой задачи.
Первый говорит, зачем проект, второй — какими словами о нём говорить.

## Всегда

- `archive/` не читать и не трогать без прямой просьбы.
- Носители контекста — по-русски; код, пути, идентификаторы и ключи JSON — как
  есть.
- Инкремент маленький: один модуль или один носитель контекста за раз.
- Правка кода не готова, пока тесты не зелёные. Как их запускать и писать —
  `docs/testing.md`.
- Новый носитель контекста или скилл — по `context-management`: раскладка и
  правила, чем файл владеет. Файл вне раскладки — дефект.
- Коммит с носителем контекста не готов, пока его не проверил `context-guard`:
  проверки диффа не достаточно.
- Снимать файл с индекса — только `git restore --staged <путь>`. `git reset` не
  применять: ошибка в аргументах стирает правки, а не только индекс.

## Индекс

Читать по необходимости, не всё сразу.

| Когда нужно | Носитель контекста |
|---|---|
| узнать, что делаем сейчас и что дальше | `docs/constitution/roadmap.md` |
| менять код: язык, запуск, раскладка модуля | `docs/constitution/tech-stack.md` |
| работать над текущей задачей | `docs/specs/features/` |
| менять или добавлять скилл | `skills/` |
